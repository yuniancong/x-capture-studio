# 数据、权限与网络说明

内容解析、勾选、排版和导出都在当前设备中执行。本版没有服务端、登录系统、埋点、遥测、广告或收费代码，不要求提供密码、Cookie 或 API Key。

扩展权限仅用于：`storage` 存储预设；`clipboardWrite` 支持用户主动复制；`scripting` 在当前 X 页面只读获取已存在的正文与关系字段。声明的站点权限覆盖 X/Twitter、twimg 媒体和字体来源域。

服务工作线程不接受任意 URL：允许 twimg HTTPS 与一个固定 Noto 发布文件，拒绝其他主机、用户名 / 密码 URL 和非标准端口。只接受本扩展来自 X 页面的消息。原媒体读取限大小、限时，扩展 fetch 不发送 Cookie、不发送 Referrer。

Stay 使用 GM 存储与 GM_xmlhttpRequest，缺失时进行能力检测和失败回退。其实现是否完全遵守 anonymous / arraybuffer 等参数需要当前版本真机验证，不能以桌面模拟结果替代。

只读探针不拉取隐藏接口。它只从请求的帖子 ID 对应的现有渲染数据中抽取正文、父帖 ID 和对话 ID；遍历限制深度和节点数，并跳过 credential 类键。不会打印或导出对象原文。

本地缓存包括样式预设、字体，以及当前编辑会话中的候选内容 / 已加载媒体。没有将推文发送给 AI 或外部图像生成网站。正文默认不做长期存储；关闭编辑器后只保留用户主动导出的文件和已保存的设置 / 字体缓存。

文件来源元数据默认开启。它有助于溯源，也可能暴露原帖作者。匿名外观默认关闭回链，但不会自动识别正文 / 图片中的身份；分享前应检查输出。

所有处理对象仍属于其原作者或权利人，工具没有为用户授予重新发布原内容的许可。
