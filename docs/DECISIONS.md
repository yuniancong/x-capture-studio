状态：已实施，2026-09-25，v1.0.0-rc.2。

用户将剩余产品决定交由助手处理并授权直接制作。下面的实现选择没有改变已确认的主线。

## 与前期讨论的边界

“支持参考功能”按本次明确目的实现，不是逐像素复制参考插件，也不是承诺目前所有真实 X 页面都已通过回归。本文与验证报告列明实际实现和待验收项。

没有实现自动递归抓全站评论、原视频下载、媒体原文件打包、远程账号同步、Chrome 商店发布和 PNG 自动分图。PNG 超限时用户可改小倍率 / 范围或选择 PDF；自动分图仍是后续可选项。

“矢量 PDF”指主要文字与几何图形；用户帖文中的图片以及个别字体缺失的 Emoji 不可能因此自动变成矢量图。它也不是无障碍认证的 Tagged PDF 或取证认证存证文件。

## 技术取舍

保持页面解析器独立，但不声称“X 改 CSS 就只需修一个文件”：真实结构变更仍可能影响 Quote、Article、加载逻辑和测试，需要针对变化回归。

画布是绘制目标，不将原 X DOM 整页截图后塞进 PDF。布局先产生统一显示命令；Canvas 输出 PNG，PDF 写入矢量命令、子集字体、媒体与链接。该结构避免 PNG 和 PDF 使用不同正文来源。

排版断行先按当前浏览器系统字体测量；PDF 使用嵌入字体并按测量宽度对齐。因此文字保留，但字形、Emoji 和少量阴影外观可能与 Apple 原生截图不同；不承诺 100% 像素一致。


## rc.2 的局部修订

没有链接不等于没有引用：保留可见引用正文和作者，将 URL 缺失作为来源未知而不是删除整个内容。只读页内公共数据用于补足确定的引用关系，不静默覆盖可见翻译。

认证标识优先使用经白名单清理的原页路径；PNG / PDF 共用路径归一化。背景图片由用户手动选择，本地优化副本；不添加系统壁纸读取桥。

Finder 来源由 OS 扩展属性表示，与标准文件元数据分开。工具内不谎称能直接写；可选用户执行工具仅改该文件字段，带确认和旧值恢复。

Stay 入口在工作台及 PDF 引擎初始化之前建立；页面按钮栏 / 不可用设置桥不能阻塞基础入口。
