详细安装说明 ↗

该指令适用 macOS、Windows、Linux，不包含请求浏览器密码或绕过浏览器安全设置的步骤。

无需 AI · 手动安装

4 步完成安装

1

下载 ZIP 并解压到固定目录

2

打开 chrome://extensions 或 edge://extensions

3

开启开发者模式，加载包含 manifest.json 的文件夹

4

确认权限，刷新 X 的帖子详情页

项目实际工作台截图（虚构演示内容），不是浏览器安装界面。

下载 Chromium rc.8

官方 Chromium 扩展加载方式参考 Chrome 扩展官方教程。

下面是 iPhone / iPad 在 Safari 中安装脚本的流程；所附 Stay 图片是开发者历史 App Store 展示图。

1

在 App Store 安装 Stay

下载并打开 Stay for Safari。这是 Safari 的扩展管理器，不是 X 原生 App 插件。

打开 Stay 官方 App Store

来自 Stay 开发者的 App Store 产品图

官方历史截图，仅供识别

2

在 Safari 中启用 Stay

较新 iOS：设置 → App → Safari 浏览器 → 扩展 → Stay → 允许扩展。

旧版 iOS：设置 → Safari 浏览器 → 扩展 → Stay。确认 X/Twitter 网站访问权限。

可参照 Apple 官方帮助核对当前系统的菜单路径。

设置 → App → Safari → 扩展 → Stay

此处为操作路径文字，不是手机截图

3

下载并导入 .user.js

先把脚本下载到“文件”App，再打开 Stay → 资料库 → +／添加脚本 → 本地文件，选择下载的文件。

请确认文件后缀是 .user.js，不要当作普通文字粘进 Safari 网页。

查看／下载 Stay rc.8

官方历史截图：认准资料库与右上角 “+”

4

在资料库激活 X Capture Studio

找到脚本，打开启用／激活开关。此前若安装过旧版，请先停用旧脚本，避免重复入口。

在 Safari 的 Stay 扩展面板也可以查看当前网站的匹配脚本和运行状态。

官方历史截图：匹配脚本及运行／停止状态

5

在 Safari 的 X 页面检查

使用 Safari 打开 x.com，进入一条帖子详情页并刷新。页面右下方可看到 X Capture / ? 入口，点击打开编辑器。

若没有显示，先核对脚本是否激活、Safari 是否允许访问当前网站，再查看 Stay 面板日志。
