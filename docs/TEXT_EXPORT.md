# 文本导出

版本：1.0.0-rc.4。两端共用同一个文本序列化器，不使用 OCR 或模型改写。

## 使用入口

工作台新增「文本」页签。底部「复制文本」直接复制纯文本；底部「文本导出」进入文本页签。
文本页签默认选 Markdown，可切换纯文本。提供复制纯文本、复制 Markdown、导出 TXT、导出 Markdown，以及独立「复制给 AI」。

复制给 AI 使用 Markdown，附一句“仅包含本次已选择、已加载的内容，不代表完整评论区”的范围说明，并把后续内容标明为引用资料。不会加入候选数量、内部 CSS、认证凭据或长篇系统提示。

## 内容与选区

所有文本输出使用当前勾选的顶层帖子和同一排序；不会私自添加未选择的主帖正文。每条内容标明主帖、作者串、相关回复或作者回应。缺少可靠关系时明确写“关系未确认”。父帖未选择或未加载时只提示关系，不伪造父帖正文。

Longer Post 使用已采集到的正文；正文仍折叠时把现有警告一并保留。Article 尽可能保留标题层级、段落、列表、引用、代码、粗体、斜体和链接。引用帖/嵌入帖保留独立作者与来源。循环、超深引用或异常巨大节点数量不会无限递归，并有未展开提示；不按固定字符数静默截断正文。

## 默认与可调字段

默认包含作者、发布时间、来源链接、回复关系、引用/嵌入帖、社区注释、投票，以及展示型媒体占位。不默认包含互动数字和采集时间。文本页签的折叠设置可以分别调整这些字段，设置保存在当前宿主中。

文本专用开关不修改 PNG/PDF 样式；外观的圆角、字号、边距和背景不改变文本。全局匿名规则仍生效：隐藏作者信息，默认移除自动附加的回链，匿名文件名不含账号或帖子 ID。只有明确开启匿名来源例外时才恢复回链。正文与原有替代文字中的身份信息不会自动清理，会显示警告。

## 媒体与来源

图片只输出 [图片] 或页面原有的替代文字；视频/GIF使用类型、已获取的时长等占位。不会根据画面编造说明，也不附加媒体 CDN 地址。正文中原有网页链接仍保留；“来源链接”控制的是自动附加的帖子回链，不是重写正文。

原帖链接使用规范的具体帖子/Article地址，不以 X 首页充当来源。没有取得链接时明确标记，不猜测作者或 ID。

## 保存与兼容回退

文件为 UTF-8，无 BOM，扩展名 .txt 或 .md。桌面点击导出后触发下载，同时保留结果窗口。手机结果窗口提供“保存文件”；支持对应文件类型的宿主还会提供系统分享。关闭分享面板不视作导出失败。

复制直接在点击/触摸回调内调用 Clipboard API，不预先等待媒体、字体或网络。写入被拒绝或接口不可用时，显示只读全文、全选按钮和文件保存入口；不谎报“已复制”。空选区不会覆盖剪贴板。文本框内的系统复制快捷键不被“复制图片”截获。
