# rc.8 权限与隐私增补

在原有本地处理及源链接导出规则上，本轮增加可选的桌面媒体请求观察。

- `webRequest` 为可选权限，只在扩展自身页面中的用户点击触发授权请求；拒绝后原功能继续可用。
- `alarms` 为新增权限，用于短时会话到期清理，避免 worker 休眠后遗留记录。最低 Chrome/Edge 120。没有申请 webRequestBlocking、cookies、history、debugger 或扩大网站 host_permissions。
- 即使授予权限，webRequest 也只在主动检查的 30 秒会话中记录指定 X 标签页顶部文档对 video.twimg.com 的媒体请求。
- 修订：内容脚本/Stay 脚本在 X 页面内用 PerformanceObserver 被动记下**本页已经请求过的** video.twimg.com 清单/文件名称（不含分片、不含其他域名，最多 160 条）。这与页面自身的资源时间线是同一信息；不需要权限、不发起请求、不读请求头或正文，只存在当前页面内存，不写入 storage、不发送到任何地方，页面关闭或脚本卸载即清除。只有与已选视频媒体 ID 唯一对应的条目才会进入导出；匿名模式或关闭“图片 / 视频标注与链接”时不附加。
- 不监听请求正文/请求头；仅从可用的响应头列表提取 Content-Type，立即丢弃其他字段。不会输出 Cookie、Set-Cookie、Authorization。
- 临时 URL（可能包含平台查询参数）仅存在当前扩展会话内存；stop、导航、关闭 tab、撤销权限、到期时清理。恢复会话重验 TTL，不存入长期 local 存储。
- 对签名地址不修改其参数；沿用 rc.7 的受限链接分享保护，默认不导出识别出的敏感 URL。明确授权本机用途后可用完整地址，但不意味着可公开分享。
- 诊断只含计数、来源与格式，不含账号、标题、帖子 ID、媒体 URL 或签名参数。测试数据均为合成，不使用用户账户。
- 新增观察不绕过 CORS、播放权限、DRM；请求观察不等于媒体文件已验证。无法明确关联的候选不会自动填入另一条帖子。
- 本轮不声称解决原项目所有隐私问题，例如主动分享含私人背景图的样式 JSON 前仍需自行检查；既有元数据和正文中的个人信息不会自动语义脱敏。
